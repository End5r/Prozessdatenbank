# Backend API (FastAPI)

Vergewissere, dass Sie im Backend Ordner sind.

## Installationsguide

```bash
uv sync
uv run uvicorn main:app --reload
```

### API 
Die API läuft unter [http:127.0.0.1:8000](http:127.0.0.1:8000)

Swagger Doku läuft unter [http://127:0.0.1:8000/docs](http://127:0.0.1:8000/docs)
